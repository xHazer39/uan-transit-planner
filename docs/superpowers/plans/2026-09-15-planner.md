# UAN Transit Planner v1 - Implementation Plan

Spec: ../../../../SPEC.txt. Design and CLI explicitly approved by the user.
Execute inline; no additional approval handoff needed.

Architecture: Python CLI runs an isolated copy of the existing TAPIR engine and its NASA parser. Astropy independently evaluates visibility and timing, ReportLab renders local summaries. No changes to the original TAPIR checkout or historical archives.

- [x] `planner.py`: input validation, NASA alias lookup and PS/PSCompPars snapshots; select a coherent BJD_TDB ephemeris, run upstream parser on that row with documented ancillary fallbacks. Cache only with explicit option. Run TAPIR CSV (all events and ground) plus original HTML in bounded date chunks. Preserve full source/provenance.
- [x] `observing.py`: interval overlap, local-night logistic window, Astropy altitude/night/moon, separate baseline percentages, linear ephemeris uncertainty and independent BJD conversion check. Classify using explicit profile heuristics, not target names. Reject missing data as favorable evidence.
- [x] `reports.py`: CSV/JSON, per-target HTML and readable PDF categories, operational summary, technical notes and ZIP. Preserve original TAPIR HTML with links; do not label tables as field charts.
- [x] `capodimonte.json`: coordinates, zone, altitude/twilight thresholds, baseline and transparent quality heuristics.
- [x] `test_planner.py`: runnable unittest checks for 915% replacement via overlap, midnight/DST, missing values, geometric versus event classification and input validation. Start with failing tests; run complete checks after implementation.
- [x] Run five named targets for 365 days and another target; inspect discrepancy statistics, all categories including empty, source metadata, and PDF renders. Record observed runtime, commands and limits in README/VALIDATION.

Constraints: CLI only; fresh catalog by default; no overwrite; Europe/Rome; end limit applies to transit not post-baseline; scientific classes independent of practical hours; all exclusions preserved; no fixed output counts; no claims about achieved photometric precision.
